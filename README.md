# Visual Studio Editor

A lightweight, browser-based visual design editor.

## Features
- Multi-page A4, landscape, square and poster canvases
- Drag-and-drop text, headings, shapes, lines, stickers, images and editable tables
- Text formatting, alignment, layer ordering and element inspector
- Live preview in a separate tab
- Save projects in browser local storage and export project JSON
- Responsive workspace

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Cloudflare Pages
